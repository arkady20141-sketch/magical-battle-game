# Магічна Битва - Файтинг Гра

## 🎮 Про гра

Це **2D піксельна файтинг гра** для планшетів та комп'ютерів, заснована на аніме **Jujutsu Kaisen** (Магічна Битва).

### Персонажі
- **Сатору Годжо** - Найсильніший чаклун
- **Юуджі Ітадорі** - Носію прокляття Сукuna
- **Мегумі Фушігуро** - Користувач шікігамі
- **Нобара Куджо** - Мисливець з молотом
- **Рюомен Сукuna** - Король проклять
- **Тоджі Фушігуро** - Вбивця проклять

### Особливості
- ✅ Піксельна графіка 2D
- ✅ Сенсорне керування для планшетів
- ✅ Клавіатурне керування для ПК
- ✅ Система комбо
- ✅ Спеціальні атаки для кожного персонажа
- ✅ **Добивання після перемоги**
- ✅ Рахунок раундів
- ✅ Вибір персонажів

## 🎯 Як грати

### Керування (Клавіатура)
- **↑** - Стрибок
- **← →** - Пересування
- **Z** - Легкий удар
- **X** - Сильний удар
- **C** - Спеціальна атака
- **V** - Блок

### Керування (Тач)
- **Стрілки** - Пересування
- **↑** - Стрибок
- **Легкий удар** - Швидка атака
- **Сильний удар** - Потужна атака
- **Спец. атака** - Використання здібностей
- **Блок** - Захист

### Механіка
1. Оберіть свого персонажа
2. Оберіть суперника
3. Бійтесь у 3 раундах
4. Перший, хто виграє 2 раунди, перемагає
5. **Після перемоги над суперником, виконайте добивання!**

## 🚀 Запуск

Просто відкрийте файл `index.html` у вашому браузері:
```bash
# На комп'ютері
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux

# На планшеті
# Завантажте папку на пристрій і відкрийте index.html у браузері
```

## 💡 Поради

- Використовуйте **комбо атаки** для максимального урону
- **Блокуйте** атаки суперника
- **Спеціальні атаки** вимагають мани
- **Добивання** активується після перемоги в раунді

## 🔧 Налаштування

Ви можете змінити налаштування в файлі `js/game.js`:
```javascript
const SETTINGS = {
    canvasWidth: 800,
    canvasHeight: 450,
    groundLevel: 350,
    gravity: 1.2,
    jumpForce: -15,
    maxRounds: 3,
    roundTime: 99,
    winScore: 2
};
```
