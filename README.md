# 🎮 Магічна Битва - Android Додаток

**Нативний Android додаток для файтингу з персонажами Jujutsu Kaisen**

---

## 📥 **ЯК ВСТАНОВИТИ АБО ЗІБРАТИ APK**

### **Спосіб 1: Встановити через Android Studio (рекомендовано)**

1. **Завантажте цей репозиторій** або клонуйте його:
   ```bash
   git clone https://github.com/arkady20141-sketch/magical-battle-game.git
   ```

2. **Відкрийте проект у Android Studio**

3. **Підключіть свій Android пристрій** (планшет) через USB з увімкненим **USB Debugging**

4. **Натисніть "Run" (▶️)** у Android Studio

5. **Оберіть свій пристрій** і дочекайтесь встановлення

6. **Грайте!** 🎮

---

### **Спосіб 2: Зібрати APK файл**

1. У Android Studio виберіть **Build → Build Bundle(s) / APK(s) → Build APK**

2. Після збірки Android Studio покаже посилання **"locate"** - натисніть його

3. Файл `app-debug.apk` буде у папці:
   ```
   magical-battle-game/app/build/outputs/apk/debug/
   ```

4. **Перенесіть APK на планшет** і встановіть через файловий менеджер

---

### **Спосіб 3: Завантажити ZIP та розпакувати**

1. **Завантажте ZIP** з цього репозиторію (кнопка "Code" → "Download ZIP")

2. **Розпакуйте** на свій комп'ютер

3. **Відкрийте папку** у Android Studio

4. **Зберіть APK** (див. Спосіб 2)

## 🔧 **НАЛАШТУВАННЯ ПРОЕКТУ**

### **Зміна імені додатку**
Відкрийте `app/src/main/res/values/strings.xml` і змініть:
```xml
<string name="app_name">Магічна Битва</string>
```

### **Зміна іконки додатку**
Замініть файли у `app/src/main/res/mipmap-*/` на свої зображення

### **Зміна персонажів**
Відкрийте `app/src/main/java/com/magicalbattle/android/Character.java`
