**Остання версія APK доступна за посиланням:**

👉 **[Завантажити APK з Releases](https://github.com/arkady20141-sketch/magical-battle-game/releases/latest)**

## 🚀 **ЯК ВСТАНОВИТИ:**

1. **Завантажте APK** з посилання вище
2. **Перенесіть файл** на свій Android планшет
3. **Відкрийте файл** через файловий менеджер
4. **Натисніть "Встановити"** (дозвольте встановлення з невідомих джерел, якщо потрібно)
5. **Грайте!** 🎮

## 📁 **Структура Проекту**


## 🛠️ **РОЗРОБКА**

Якщо ви хочете змінити код або зібрати самостійно:

### **Локальна збірка:**

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/arkady20141-sketch/magical-battle-game.git
   ```

2. Відкрийте у Android Studio

3. Зберіть APK:
   ```bash
   ./gradlew assembleDebug
   ```

4. APK буде за шляхом:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
